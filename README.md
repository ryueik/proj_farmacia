## 📖 Sobre o Projeto

O **proj_farmacia** é um projeto **acadêmico e fictício** desenvolvido para a disciplina de **Projeto Integrador Transdisciplinar (PIT)** do curso de **Gestão da Tecnologia da Informação**.

O grande diferencial deste trabalho é a **aplicação prática de Inteligência Artificial em todas as etapas do desenvolvimento web** — desde a estruturação do código HTML/CSS, passando pela criação de textos (copywriting) e design, até a seleção de imagens de bancos gratuitos e geradas por IA. O objetivo foi demonstrar como ferramentas de IA podem acelerar a entrega de um produto digital **moderno, responsivo e funcional**, sem abrir mão de um **código limpo, semântico e didático**.

> [!NOTE]
> **Este é um projeto fictício.** A "Farmácia Vida & Saúde" não existe. Todo o conteúdo, marca, produtos e informações foram criados exclusivamente para fins educacionais e de demonstração técnica.

### 🧭 Principais Seções do Site

| Seção | Descrição |
|:------|:----------|
| 🏠 **Hero / Destaque** | Banner principal com chamada visual e CTA para o usuário. |
| 💊 **Categorias de Produtos** | Vitrine organizada por categorias (medicamentos, higiene, beleza, etc.). |
| 🩺 **Serviços & Benefícios** | Apresentação dos diferenciais e serviços oferecidos pela farmácia. |
| ℹ️ **Sobre a Farmácia** | História fictícia, missão, visão e valores da marca. |
| 📞 **Rodapé / Contato** | Informações de contato, redes sociais e localização. |

## ✨ Recursos e Destaques do Site

| Recurso | Descrição |
|:--------|:----------|
| 📱 **Design Responsivo** | Layout adaptável para desktop, tablet e smartphone (mobile-first). |
| ♿ **Acessibilidade Básica** | Uso de HTML semântico, contraste adequado e textos alternativos (`alt`). |
| 🖼️ **Imagens Otimizadas** | Mídias selecionadas do Pixabay e geradas por IA, com foco em leveza e performance. |
| 🧑‍💻 **Código Didático** | HTML/CSS organizado, comentado e de fácil leitura para fins de estudo. |
| 🎨 **UI Moderna** | Paleta de cores coerente, tipografia limpa e microinterações em CSS. |
| ⚡ **Deploy Contínuo** | Publicação automatizada via Vercel integrada ao repositório. |

> [!TIP]
> Explore o código comentado para entender como cada seção foi construída — é um excelente material de estudo para quem está iniciando em desenvolvimento web com apoio de IA.

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**

```bash
git clone https://github.com/ryueik/proj_farmacia.git
```

2. **Acesse a pasta do projeto:**

```bash
cd proj_farmacia
```

3. **Abra o arquivo `index.html` no navegador:**

- Basta dar um duplo clique no arquivo `index.html`, **ou**
- Utilize a extensão **Live Server** no VS Code para recarregamento automático.

> [!NOTE]
> Não há dependências, build ou instalação de pacotes. O projeto é 100% estático (HTML + CSS).
